## 後回しリスト

提出に必須でないもの。時間が余ったら着手する。

| 項目 | 理由 |
|---|---|
| 自作語の追加（`custom-words.json`） | 提出版は配布300語のみ。id採番方針（1001〜）だけ決めてある |
| セッション途中離脱の復元 | 1セット3〜5分なので実害が小さい。単一ページ遷移の設計上の割り切り |
| localStorage スキーマのマイグレーション | 不一致なら破棄する方針。本人1名・提出まで数日という前提 |
| 卒業した語の履歴表示 | ③の実感は「カードが減る」で足りる。専用画面を作らない方針 |
| `/review` のページング・フィルタ | 同上 |
| Haiku 4.5 との速度比較 | `AI_MODEL` で切替可能にしてある。遅いと感じたら測る |

### 撤退ライン（時間が足りなくなったらこの順で削る）

| 優先度 | 内容 |
|---|---|
| 絶対に削らない | 300語からの出題／AIフィードバック1つ／10問で終わる／APIキーを隠す |
| 削らない | 原因分類／SCORE（正解率＋即答率）／テンポ／復習カードの保存 |
| 最初に簡略化 | `/review` を作らずホームに直接並べる |
| 最初に削る | デザインの作り込み／アニメーション |

`response_ms` が得点システムの土台なので、回答時間の計測は「絶対に削らない」。
